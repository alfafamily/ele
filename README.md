# ELE

Веб-сервис (self-hosted, B2B) учёта имущества, доступа и сотрудников компании.

## Возможности

- **Учёт имущества:** оборудование, лицензии, транспорт, инструменты,
  корпоративная связь, средства доступа.
- **Виды и реквизиты:** создание видов имущества, настройка для них реквизитов
  и правил учёта.
- **Сотрудники и размещение:** закрепление имущества за сотрудником
  (с подтверждением от сотрудника), рабочим местом, местом общего пользования
  или складом.
- **Техобслуживание:** регламенты ТО, планы обслуживания, проведение работ
  с учётом пробега и материалов, напоминания.
- **Ролевая система для пользователей:** тонкая настройка по ролям для
  пользователей, какие разделы системы и действия в них доступны.
- **Отчёты:** построение отчётов по имуществу в разрезе сотрудника или мест
  компании.
- **Прочее:** настройки резервного копирования, доступа и аутентификации
  в сервис, уведомлений по событиям с имуществом и многое другое.

## Установка на сервер

«Одной строкой» (проверит Docker, склонирует репозиторий, интерактивно создаст
`.env` и поднимет стек):

```sh
curl -fsSL https://raw.githubusercontent.com/alfafamily/ele/main/install.sh | bash
```

Проверить установщик перед запуском (контрольная сумма SHA-256), требования к
серверу, ручная установка, обновление версии и восстановление из резервной
копии — в [`docs/INSTALL.md`](docs/INSTALL.md).

## Стек

Django + DRF, PostgreSQL, React (Vite) SPA, Caddy (реверс-прокси, авто-TLS),
docker-compose.
